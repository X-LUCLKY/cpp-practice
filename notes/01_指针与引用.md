# 01 · 指针与引用

## 一句话结论

指针是"存地址的变量"，引用是"变量的别名"；指针可以为空、可以改指向，引用一旦绑定就不能换。

## 关键点

- `int a = 1; int* p = &a;` —— `p` 存的是 `a` 的地址，`*p` 取出值
- `int& r = a;` —— `r` 就是 `a` 的另一个名字，改 `r` 等于改 `a`
- 指针可以不初始化（危险），引用**必须**在定义时绑定
- 函数传参：想改外部变量用 `int&`；想把大对象传进去又不想拷贝用 `const T&`
- `nullptr` 比 `NULL` 安全（有类型）

## 代码示例

```cpp
#include <iostream>
using namespace std;

void swapByRef(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}

void swapByPtr(int* a, int* b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main() {
    int x = 1, y = 2;
    swapByRef(x, y);          // 1 2 -> 2 1
    swapByPtr(&x, &y);        // 2 1 -> 1 2
    int* p = nullptr;         // 何时用都比较安全
    int& r = x;               // r 是 x 的别名
    cout << x << ' ' << y << ' ' << (p == nullptr) << ' ' << (r == x) << '\n';
}
```

## 我踩过的坑

- 现象：函数里改了参数，出来没变
- 原因：用的是**值传递**（`int a`），改的是副本
- 解决：需要修改外部变量时改成 `int&`

- 现象：`*p` 程序崩溃
- 原因：`p` 是野指针 / `nullptr`
- 解决：指针定义时初始化（`= nullptr`），用前判断
