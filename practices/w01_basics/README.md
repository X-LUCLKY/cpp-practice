# w01 · 基础输入输出与循环

## 题目

1. 读入一个整数 `n`，输出 `1 + 2 + ... + n` 的结果。
2. 读入 `n`（n ≤ 50），输出前 `n` 个斐波那契数（`1 1 2 3 5 ...`）。
3. 读入一行字符串（含空格），输出它的长度和反转结果。

## 思路记录

- 第 1 题：直接用 for 循环累加；注意 `n` 可能很大时用 `long long`。
- 第 2 题：用两个变量滚动，不要开数组。
- 第 3 题：`getline` 读整行，`reverse` 反转后输出。

## 卡住的地方

（写在这里，下次复习就是你的错题本）

- 例：读字符串前如果用过 `cin >> n`，要先用 `cin.ignore()` 清掉换行，否则 `getline` 会读到空行。
