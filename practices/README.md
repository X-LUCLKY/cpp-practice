# 每周练习

按周归档，一周一个文件夹，命名 `wNN_主题`。

| 文件夹 | 主题 | 状态 |
|---|---|---|
| `w01_basics` | 输入输出、变量、循环 | 进行中 |
| `w02_loops` | 数组与循环综合 | 待开始 |
| `w03_pointers` | 指针与引用 | 待开始 |

## 每个练习文件夹里放什么

```
wNN_主题/
├─ README.md     题目、思路、卡住的地方
├─ main.cpp      代码
└─ output.txt    运行结果（可选）
```

## 提交节奏

- 每完成一个练习：`git commit -m "feat: w01 完成 xx 练习"`
- 每两周至少 1 次推送
- 不用追求"完美代码"，**跑通 + 写清楚思路**就够
